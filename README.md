# Стажёр инженер по тестированию Go, Рантайм рекомендательных продуктов

Микросервис управления статьями и системой рейтингов с полным покрытием модульными и интеграционными тестами. Проект спроектирован для демонстрации практических навыков тест-дизайна, написания автотестов на Go и работы со стандартной библиотекой `net/http/httptest`.

# Стек технологий
* Язык: Go 
* Тестирование: `testing`, `net/http/httptest`, Table-driven testing
* Хранилище: In-Memory Storage с поддержкой конкурентного доступа (`sync.RWMutex`)
* Формат данных: RESTful JSON API

# Архитектура проекта
* `models.go` — Доменные сущности (`Article`, `Rating`) и методы валидации данных.
* `storage.go` — Потокобезопасное хранилище и логика расчёта среднего рейтинга.
* `api.go` — HTTP-эндпоинты и обработчики запросов.
* `models_test.go` — Unit-тесты валидации по методологии граничных значений.
* `storage_test.go` — Тестирование CRUD-операций и математики рейтинга в хранилище.
* `api_test.go` — Интеграционные тесты HTTP-хэндлеров и статусов ответа.

# Применённые техники тест-дизайна

1. Граничные значения (Boundary Value Analysis):
   * Длина заголовка статьи: $L = 2$ (ошибка), $L = 3$ (успех).
   * Оценка статьи: $Score = 0$ (ошибка), $Score = 1$ (успех), $Score = 5$ (успех), $Score = 6$ (ошибка).
2. Классы эквивалентности (Equivalence Partitioning):
   * Валидные строки и пустые значения контента.
   * Положительные и отрицательные идентификаторы статей (`ID <= 0`).
3. Негативное тестирование API:
   * Передача повреждённого тела запроса (Malformed JSON).
   * Запрос несуществующих ресурсов (HTTP 404 Not Found).
   * Некорректные типы query-параметров (`id=abc` $\rightarrow$ HTTP 400 Bad Request).
